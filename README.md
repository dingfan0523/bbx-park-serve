1、简介
    该项目是一个CUD框架类型的示例项目，请大家参考或者在该示例的基础上进行开发
    其中集成了一些中台的公共微服务功能，基于SpringBoot开发的项目，通过maven来导
    入你的项目。

2、导入项目
    通过Maven进行导入项目，集团内部通过nexus搭建了一个maven私有库，所以
    maven的setting.xml文件应该进行一定的修改,可以咨询框架组支持人员。
    
3、应用注册申请以及应用申请微服务
    由于项目使用了中台项目组开发的微服务，所以项目首先要注册申请接入中台，待申请
    完成后，会通过内网邮箱发送"鉴权信息"，这里的信息要配置在yml文件里面的最下面a
    ep。(理解为访问中台的凭据-appid、appSecret),然后应用要申请相关的微服务(请申
    请用户中心服务、集团统一授权，这两个请申请)。具体是在http://csp上申请(请找甲
    方项目经理申请)，可以找中台项目组和CUD项目组要相关的申请文档。
    
4、yml文件配置数据库脚本信息
    先在数据库执行示例sql脚本（初始化表脚本以及初始化数据脚本），在yml配置文件(以application.yml指向的配置文件为
    准)配置好你的数据库相关信息。
    
5、启动后端   
    找到cud4demo文件中的src/main/java/com/cgnpc/cuddemo/Application.java，启动里面的main方法。
    后端成功启动。
    
6、启动前端
    前后端已分离，所以前端的代码在cud4demo-ui中，进入目录，cmd打开命令提示符或者使用vscode启动，执行npm run dev命令。访问http://localhost:8010 (示例的默认的前端端口)
    
7、部署测试环境
    项目是前后端分离部署的，前端部署在nginx上，后端部署在中台的devops或者虚拟机tomcat上，这里也
    要申请nginx、应用服务器以及devops资源。可以在http://csp上找到CUD框架前后端部署指引或者找
    CUD项目组要。
